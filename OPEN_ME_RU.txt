WINX STUDIO — ASSIGNMENT 6

1. Распакуй весь ZIP. Не открывай HTML прямо внутри архива.
2. Открой index.html или запусти папку через VS Code Live Server.
3. Нужен интернет: jQuery, Bootstrap и фотографии загружаются с внешних сайтов.

Показать задания:
Home — счётчики 6/7/3, старый рейтинг.
Products — поиск, подсказки (стрелки и Enter), категории и избранное, уведомления.
Tips — поиск по FAQ с подсветкой совпадений.
Contact — заполни все обязательные поля и нажми Validate Message: появится спиннер на 1,4 секунды. Пустая форма сначала показывает ошибки. Пошаговая форма Assignment 5 сохранена.
Любая страница — полоска прокрутки вверху, Copy email внизу, отложенная загрузка фотографий при прокрутке.
F12 → Console — сообщение jQuery is ready!

Для копирования лучше localhost (Live Server) или HTTPS. Если браузер блокирует буфер, сайт честно покажет ошибку — скопируй email вручную.

Формы учебные: данные не отправляются, аккаунты не создаются.
